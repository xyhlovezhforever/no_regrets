## 🚀 推荐的打包流程

### 方案 A：HBuilderX 云打包（最简单）⭐

1. **下载 HBuilderX**
   - 访问：https://www.dcloud.io/hbuilderx.html
   - 下载"App 开发版"
   - 安装并打开

2. **导入项目**
   - 文件 -> 导入 -> 从本地目录导入
   - 选择 `frontend` 目录

3. **获取 AppID**
   - HBuilderX 会自动生成
   - 或在 manifest.json 可视化界面点击"重新获取"

4. **云打包**
   - 发行 -> 原生App-云打包
   - 选择 Android（或 iOS）
   - 使用"DCloud公用证书"（测试用）
   - 点击"打包"
   - 等待 3-10 分钟
   - 下载 apk 文件

5. **测试**
   - 将 apk 传到手机
   - 安装并测试

### 方案 B：命令行构建 + HBuilderX 打包

```bash
# 1. 构建资源
npm run build:app-android

# 2. 使用 HBuilderX 云打包
# （步骤同方案 A）
```

## 📱 打包后的文件

- **Android**: `.apk` 文件（可直接安装）
- **iOS**: `.ipa` 文件（需通过 TestFlight 或企业签名）

## ⚠️ 重要提示

1. **AppID 问题**
   - 当前使用占位符 `__UNI__XXXXXX`
   - 在 HBuilderX 中会自动替换为真实 AppID
   - 不影响打包流程

2. **证书选择**
   - **测试阶段**：使用 DCloud 公用证书
   - **正式发布**：需要自己的签名证书
     - Android: keystore 文件
     - iOS: 开发者证书 + 描述文件

3. **网络请求**
   - 确保后端 API 地址配置正确
   - App 建议使用 https
   - 检查跨域和域名白名单配置
